# SHIR LAVY — Design guidelines (inspired by the "Impeccable" approach)

Apply on every design task in this project.

## Product context
- Brand: SHIR LAVY — Aesthetics & Academy. Women-only boutique clinic, PMU academy, online shop.
- Language: Hebrew, RTL. Audience: Israeli women seeking premium, natural results.
- Tone: elegant, warm, confident, personal. No exaggerated claims, no invented facts.

## Process
- Before designing, decide the surface mode: Persuade (landing/marketing), Operate (shop, checkout, forms), Read (info/FAQ), Experience (signature moments like the map). Persuade/Experience = bold, distinct POV. Operate/Read = precision, restraint, familiar patterns.
- Redesign = treat the old look as anti-reference and fully replace it. Refinement = keep identity, change only what's in scope. Never half-polish a discarded look.
- Finish the job: complete deliverables, placeholders only for assets the user must supply.

## Anti-patterns to avoid
- Generic AI tells: one overused sans for everything, purple/blue gradients, gradient text, glassmorphism by default, cards nested in cards, rounded-square icon tiles above headings, side-stripe accent borders, gray text on colored backgrounds, filler stats/icons.
- Template sameness: every section a repeated card grid.

## Quality bar
- Verify contrast (text 4.5:1). Respect prefers-reduced-motion. No horizontal overflow. Real responsive behavior (mobile designed, not compressed). Touch targets ≥ 44px.
- Deliberate typography hierarchy, consistent spacing scale, purposeful motion only.

## Current brand direction (user-approved)
- Coming-soon page: warm kraft-brown background with subtle gold-foil logo, soft gradient glow, Heebo light headline, Assistant body.
- User dislikes: pale/washed-out palettes, beige-brown overload, busy multi-logo backgrounds, serif headline fonts tried so far.
- User likes: clean, minimal, rounded corners, elegant brand-bag aesthetic.
